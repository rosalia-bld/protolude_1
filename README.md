# Documentation TP1 *Protolude*
## Environnement
Mon jeu se déroule dans une zone forestière entourée de montagnes, avec quelques maisons d’un petit village ancien. Le décor est composé d’arbres, de roches, de pentes et d'une rivière. 
## Mécaniques
- But : Atteindre l'unique maison au sommet des montagnes
- Danger : Rivière (Si tombe à l'intérieur=respawn au début)
- Objet physique : Tronc d'arbre qui roule d'une pente
- Prérequis : Clé cachée dans le village -> Ouvre le portail qui permet de monter la montagne
