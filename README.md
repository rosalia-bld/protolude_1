# Documentation TP1 *Protolude*
## Environnement
Mon jeu se déroule dans une zone forestière entourée de montagnes, avec quelques maisons d’un petit village ancien. Le décor est composé d’arbres, de roches, de pentes et d'une rivière. 
## Mécaniques
- But : Atteindre la maison de grand-maman
- Danger : Rivière (Si tombe à l'intérieur=respawn au début) et troncs d'arbre (Si touche joueur=respawn)
- Objet physique : Troncs d'arbre qui roule d'une pente
- Prérequis : Clé cachée dans le village -> Ouvre le portail qui permet d'accéder à la maison de grand-maman
